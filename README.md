# kurve-legal

The public home of Kürve's privacy policy and support page, served by GitHub Pages (plain Markdown, built by Jekyll with the built-in `jekyll-theme-minimal` theme; no analytics, no external fonts or scripts).

- Privacy policy: https://devyus.github.io/kurve-legal/privacy/
- Support: https://devyus.github.io/kurve-legal/support/

The source of truth for the policy text is `docs/privacy-policy.md` in the Kürve app repository. Changes here must be copied from it, not made here first.
